# V31 — Meilleurs paramètres globaux

Cette version repart de la V30 et ajoute une couche finale stable : `assets/css/v31-best-settings.css` et `assets/js/v31-best-settings.js`.

Objectif : garder le site existant, préserver le cercle PSSR, mais harmoniser toutes les pages avec les meilleurs paramètres globaux :

- largeur de contenu mieux utilisée sur ordinateur ;
- respiration régulière entre les sections ;
- textes centrés quand c’est utile, alignés à gauche sur mobile ;
- typographie plus propre ;
- boutons équilibrés ;
- cartes cohérentes ;
- formulaires plus lisibles ;
- footer stable, non décalé ;
- menu burger plus robuste ;
- retour en haut discret ;
- images lazy-loading ;
- pas de modification Firebase ;
- pas de modification du cercle PSSR.
