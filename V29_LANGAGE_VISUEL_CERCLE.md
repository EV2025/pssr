# V29 — Langage visuel inspiré du cercle PSSR

Cette version prend le style du cercle PSSR comme référence graphique pour harmoniser le reste du site : cartes blanches, bordures lilas, badges arrondis, lignes colorées, ombres douces et grandes marges.

Le cercle PSSR lui-même n’a pas été modifié : contenu, étapes, interactions, logique et couleurs internes restent ceux de la version validée.

Fichier principal ajouté : `assets/css/v29-circle-language.css`.
