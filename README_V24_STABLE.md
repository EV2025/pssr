# PSSR — Version V24 stable propre

Cette version repart de la dernière version fonctionnelle, mais supprime l'empilement visuel des anciennes versions.

## Objectif

- Un seul fichier CSS principal : `assets/css/stable-v24.css`
- Un design cohérent sur les pages publiques, membre et admin
- Menu, cartes, boutons, formulaires, calendrier et footer harmonisés
- Super cercle PSSR conservé sans modification de contenu, logique ou JavaScript
- Pas de changement Firebase / Firestore

## À envoyer sur GitHub

Copier tout le contenu de ce dossier à la racine du dépôt GitHub Pages `pssr`, puis faire :

1. Commit to main
2. Push origin
