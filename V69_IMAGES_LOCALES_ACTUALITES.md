# V69 — Actualités avec images locales

- Les pages Actualités ne renvoient plus vers les URLs médias de l’ancien site.
- Les balises image utilisent désormais `/pssr/wp-content/uploads/...`.
- Les références visibles à l’ancien forum ont été supprimées des pages publiques.
- Les préfixes techniques du type « Texte harmonisé / contenu repris » ont été retirés.
- Le dossier `wp-content/uploads` est prêt à recevoir les images réelles.

Important : un export WordPress XML référence les images, mais ne contient pas les fichiers binaires.
