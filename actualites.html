Mode d’emploi

Comment ajouter un prochain article ou une vidéo ?

  1. Pour un nouvel article : crée une nouvelle page dans le dossier actualites/, puis ajoute une carte dans actualites.html.
  2. Pour intégrer une vidéo : récupère l’identifiant YouTube après watch?v=, puis utilise le format https://www.youtube.com/embed/ID_DE_LA_VIDEO.
  3. Pour publier : envoie les fichiers modifiés sur GitHub, puis clique sur Commit changes.
