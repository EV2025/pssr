Mode d’emploi

Comment ajouter un prochain article ou une vidéo ?

  1. Nouvel article : crée une nouvelle page dans actualites/, puis ajoute une carte dans actualites.html.
  2. Vidéo YouTube : récupère l’identifiant après watch?v=, puis insère https://www.youtube.com/embed/ID_DE_LA_VIDEO.
  3. Publication : envoie les fichiers sur GitHub et valide avec Commit changes.
