Mode d’emploi

Comment ajouter un article ou une vidéo ?

  1. Pour un article : ouvre actualites.html, copie un bloc <article class="news-card-v60">, puis modifie le titre, la date, le résumé et le lien.
  2. Pour une vidéo YouTube : copie l’adresse de ta vidéo, récupère le code après watch?v=, puis remplace l’identifiant dans https://www.youtube.com/embed/ID_DE_LA_VIDEO.
  3. Pour publier : envoie le fichier modifié sur GitHub dans le dépôt du site, puis clique sur Commit changes. La page sera ensuite visible sur le site.
